# BLEY-Dashboard-Dissertation
BUSI1783_BA_Project

## Overview
This project develops an interactive dashboard to analyse early years outcomes (GLD) across Greater London boroughs.

## Objectives
- Integrate borough-level datasets (DfE, ONS, Ofsted)
- Analyse relationships between socioeconomic factors and GLD
- Develop a decision-support dashboard for non-technical users

## Data Sources
- Department for Education (GLD, FSM, SEN)
- Office for National Statistics (Population, Ethnicity)
- Ofsted (Childcare, Provider Ratings)
- MHCLG (IDACI)

## Methods
- Data cleaning and integration using Python
- Correlation and regression analysis
- Interactive dashboard (Shiny)
